# Ecommerce Automation Framework

## 📖 Project Overview
This project is an end-to-end UI automation framework developed for the SauceDemo e-commerce website.  
It automates key user workflows including login, product selection, cart management, and checkout process.

## 🛠️ Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)

## ✅ Automated Test Scenarios
- User Login
- Add to Cart
- Remove from Cart
- Checkout Process
- Order Confirmation

## 🏗️ Framework Design
- Page Object Model (POM) structure
- Reusable utility classes
- TestNG annotations & assertions
- Maven dependency management

## ▶️ How to Run the Project
1. Clone the repository
2. Import as Maven Project
3. Run the `testng.xml` file
